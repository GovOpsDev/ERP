Zero uses the native rate at request date. Submission captures the rate; later rate-table changes do not rewrite approval thresholds or commitments. Existing target rows retain their own company's currency and legacy rate1 without fabricating approval evidence. The first schema upgrade backfills each old request from its company, not from the installing user's company.

Requisition and RFQ preserve that currency and authorized manual rate; selecting a vendor cannot silently reprice the same numbers in another currency. Direct manual edits still require Budget/accounting management and finite nonnegative rates.
