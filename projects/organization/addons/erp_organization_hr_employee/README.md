# erp_organization_hr_employee

Optional Odoo 20 Community bridge restricting employee, public employee and employee-version records by primary and effective additional organizations. Employees never scoped to an organization retain native visibility; employees with scope history remain restricted even when no organization is effective. Other HR-related models are not fully audited. See project `docs/employee-multi-organization-design.md` and `docs/employee-operating-unit.md` before rollout.
