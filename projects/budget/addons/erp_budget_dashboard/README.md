# GovOpsDev Project Budget BI

เพิ่มภาพรวมงบประมาณจริงในแอป **แดชบอร์ด → งบประมาณ → งบประมาณโครงการ · บริษัทปัจจุบัน**

- แสดงวงเงินจัดสรร ผูกพันสุทธิ ใช้จริงสุทธิ รายการไม่ระบุประเภท และคงเหลือ
- กรองปี/รอบงบประมาณ โครงการ/บัญชีวิเคราะห์ หน่วยงาน และ KPI
- กราฟแยกโครงการ หน่วยงาน และประเภทใบขอซื้อ ใบสั่งซื้อ สัญญา รายจ่าย เงินทดรอง และใช้จริง
- เมนู **วิเคราะห์งบประมาณ** เปิด Pivot, กราฟ และรายการ สามารถเพิ่ม/สลับกลุ่มและมาตรวัด คลิกยอด Pivot เพื่อดูรายการ และส่งออกตามสิทธิ์
- รายงาน **งบประมาณแยกกองทุน** แยกจากภาพรวมโครงการ เพราะเป็นวงเงินควบคุมอีกระดับที่อาจซ้อนกับยอดโครงการ

## ขอบเขตและการอ่านยอด

รายงานอ่านจากวงเงิน `erp.budget.control` ที่ active และสถานะ open กับบัญชีรายการ `erp.budget.move` ปัจจุบัน ไม่ใช่แผนร่างหรือรายงานยอดคงเหลือ ณ วันย้อนหลัง ไม่มีข้อมูลตัวอย่างจำลองเมื่อยังไม่มีวงเงิน

ยอดกลับรายการมีเครื่องหมายลบและรวมสุทธิในประเภทเดิม:

`วงเงินจัดสรร = ผูกพันสุทธิ + ใช้จริงสุทธิ + รายการไม่ระบุประเภท + คงเหลือ`

รายการที่ระบบเดิมยังไม่กำหนดประเภทแสดงแยก ไม่อนุมานให้เป็นการใช้จริง เวลาบันทึกในรายงานรายการคือเวลาเข้าระบบ ไม่ใช่วันที่บัญชีของเอกสารต้นทาง

โครงการอ้างอิงบัญชีวิเคราะห์ หากหลาย Project ใช้บัญชีวิเคราะห์เดียวกัน ยอดแสดงรวมในบัญชีนั้นหนึ่งครั้ง ไม่แยกเงินซ้ำให้แต่ละ Project รายงานแต่ละแถวของภาพรวมคือวงเงินควบคุมหนึ่งรายการ สามารถแยก KPI และหน่วยงานเพิ่มเติมใน Pivot

## บริษัทและสิทธิ์

ทุกช่องทาง (กราฟ, Pivot, รายการ, export) จำกัดเฉพาะ **บริษัทปัจจุบัน** แม้เลือกหลายบริษัทในตัวสลับบริษัท เพื่อไม่รวมต่างสกุลเงิน สลับบริษัทแล้วเปิด/โหลด Dashboard ใหม่ ตัวเลขใช้สกุลเงินของบริษัทปัจจุบัน ไม่เปลี่ยน USD เป็น THB ด้วยการแทนสัญลักษณ์

ต้องมีกลุ่ม Budget User และสิทธิ์หน่วยงานเดียวกับระบบงบประมาณเดิม กลุ่ม Budget All Organizations ขยายได้เฉพาะหน่วยงานที่เปิดใช้งานภายในบริษัทปัจจุบัน รายงานเป็น read-only รวมถึงผู้จัดการ ห้ามแก้ยอดผ่านรายงาน ให้ดำเนินการที่เอกสารต้นทางตามขั้นตอนปกติ

## ติดตั้ง

เพิ่ม addon นี้ใน addons path และติดตั้ง `erp_budget_dashboard` โดยต้องมี `erp_budget`, `project`, `spreadsheet_dashboard` ของรุ่นที่รองรับ Odoo 20 อยู่แล้ว ไม่มีการแก้ Odoo core และไม่มีการเขียนยอดธุรกิจหรือเปลี่ยนสิทธิ์ผู้ใช้ในการติดตั้ง

ทดสอบด้วย `--test-enable --test-tags /erp_budget_dashboard --stop-after-init` บนฐานทดสอบสำเนา
