แดชบอร์ด

อ่านภาพรวม เลือกขอบเขตและช่วงเวลา และตรวจกลับไปยังเอกสารต้นทาง

สำหรับ ผู้บริหาร ผู้ตรวจสอบ และผู้ใช้อ่านรายงานตามสิทธิ์ · ปรับปรุง 31 ตุลาคม 2569

เปิดระบบคู่มือทุกแอป

ไม่พบข้อความ ลองใช้คำอื่นหรือล้างคำค้นหา

เริ่มใช้งานและอ่านหน้าจอ

เปิดแอปจากเมนูหลัก แล้วเลือก คู่มือการใช้งาน คู่มือเปิดในแท็บใหม่เพื่อให้ดูพร้อมหน้าทำงานได้ เลือกแอปอื่นจากรายการด้านซ้าย หรือค้นหาคำในคู่มือนี้ และใช้ปุ่มพิมพ์ / บันทึก PDF เมื่อต้องการสำเนา

  • ตรวจบริษัทที่มุมขวาบนและหน่วยงานในเอกสารก่อนสร้างหรืออนุมัติ เมนูและปุ่มขึ้นกับสิทธิ์ของบัญชี
  • หลังแก้ข้อมูล ให้ใช้ปุ่มบันทึก / ไอคอนบันทึกตามที่แบบฟอร์มแสดง แล้วตรวจสถานะและเลขเอกสารก่อนออกจากหน้า
  • ภาพประกอบเป็นข้อมูลจำลอง ชื่อรายการ ภาษา หรือเลขเอกสารอาจต่างจากบัญชีของคุณ ตัวเลขในภาพไม่ใช่ค่าที่ต้องกรอก
  • ข้อความผิดเงื่อนไขให้จดเลขเอกสารและข้อความที่แสดง ส่งให้ผู้รับผิดชอบงานตรวจ อย่าส่งรหัสผ่านหรือข้อมูลเข้าสู่ระบบ
  • ถ้าคู่มือเปิดแล้วภาพหรือภาษาเก่าค้าง ให้บันทึกงานในหน้าระบบก่อน แล้วรีเฟรชแท็บคู่มือ

ใช้แดชบอร์ดเพื่อพิจารณางาน

แดชบอร์ดแสดงข้อมูลสรุปตามชุดที่ติดตั้ง สิทธิ์ และตัวกรองในขณะนั้น บางชุดเป็นข้อมูลทั่วไปของ Odoo ไม่ใช่รายงานงบประมาณ NSTDA โดยเฉพาะ ให้ตรวจชื่อชุดข้อมูลและความหมายตัวชี้วัดก่อนนำไปใช้

  1. เลือกแดชบอร์ด
  2. กำหนดตัวกรอง
  3. อ่านยอดและหน่วย
  4. ตรวจเอกสารต้นทาง

เลือกและอ่านแดชบอร์ด

  1. เปิดแอปแดชบอร์ด เลือกรายงานหรือหมวดที่ตนมีสิทธิ์อ่าน
  2. ตรวจบริษัทที่เปิดอยู่และช่วงวันที่ในตัวกรองของแดชบอร์ดนั้น
  3. อ่านหัวข้อ หน่วย สกุลเงิน และการจัดกลุ่มก่อนเทียบตัวเลข
  4. หากมีลิงก์หรือการเจาะข้อมูล ให้เปิดเพื่อตรวจรายการที่รวมอยู่ ไม่ใช้ภาพรวมแทนเอกสารอนุมัติ

เทียบยอดกับเอกสารต้นทาง

ต้องเทียบวิธีพิจารณา
ช่วงเวลาวันที่เอกสาร วันลงบัญชี และงวดอาจไม่ใช่วันเดียวกัน
บริษัทและหน่วยงานตรวจตัวกรองรายงานและขอบเขตบัญชีผู้ใช้
สถานะยอดร่าง ยอดยืนยัน และยอดลงบัญชีอาจรวมคนละชุด
สกุลเงินตรวจว่าแสดงสกุลเงินบริษัทหรือเอกสาร และใช้อัตราใด
นิยามยอดยอดจัดซื้อ ยอดใช้จริง และวงเงินคงเหลือไม่ใช่ตัวชี้วัดเดียวกัน

ข้อมูลไม่ตรงหรือยังไม่ปรากฏ

  1. ตรวจตัวกรองทั้งหมดและวันที่ของข้อมูลที่นำมาเทียบ
  2. เปิดเอกสารต้นทางและดูสถานะล่าสุด รวมถึงรายการกลับรายการ
  3. รีเฟรชหน้าหรือใช้ปุ่มปรับข้อมูลที่แดชบอร์ดนั้นมี แล้วตรวจอีกครั้ง
  4. หากยังไม่ตรง ให้แจ้งชื่อแดชบอร์ด ตัวกรอง เลขเอกสาร และตัวเลขที่คาดหวังแก่ผู้รับผิดชอบ

คำถามที่พบบ่อย

อาการตรวจอย่างไร
ไม่มีแดชบอร์ดบางชุดตรวจการติดตั้งชุดรายงานและสิทธิ์ ไม่ใช่ทุกบัญชีจะเห็นทุกชุด
มีสิทธิ์ดูภาพรวมแต่เปิดรายละเอียดไม่ได้การเจาะข้อมูลยังตรวจสิทธิ์เอกสารต้นทาง
ยอดต่างจากผู้ใช้อื่นเทียบบริษัท ช่วงเวลา ตัวกรอง และสิทธิ์ก่อนสรุปว่ารายงานผิด
ต้องการอนุมัติจากแดชบอร์ดเปิดเอกสารต้นทางและดำเนินการตามปุ่มและสิทธิ์ของแอปนั้น

คู่มือที่เกี่ยวข้อง

ข้อมูลงบประมาณพื้นฐานออกใบแจ้งหนี้และการเงินสั่งซื้อ
คู่มือนี้อธิบายการใช้งานที่มีในระบบ GovOpsDev ERP ชื่อข้อมูลจริงและสิทธิ์อาจแตกต่างตามการตั้งค่า หากต้องแก้สิทธิ์หรือการตั้งค่าระบบ ให้ผู้ดูแลที่ได้รับมอบหมายดำเนินการ กลับด้านบน
