เปิดระบบคู่มือทุกแอป

ไม่พบข้อความ ลองใช้คำอื่นหรือล้างคำค้นหา

เริ่มใช้งานและอ่านหน้าจอ

เปิดแอปจากเมนูหลัก แล้วเลือก คู่มือการใช้งาน คู่มือเปิดในแท็บใหม่เพื่อให้ดูพร้อมหน้าทำงานได้ เลือกแอปอื่นจากรายการด้านซ้าย หรือค้นหาคำในคู่มือนี้ และใช้ปุ่มพิมพ์ / บันทึก PDF เมื่อต้องการสำเนา

  • ตรวจบริษัทที่มุมขวาบนและหน่วยงานในเอกสารก่อนสร้างหรืออนุมัติ เมนูและปุ่มขึ้นกับสิทธิ์ของบัญชี
  • หลังแก้ข้อมูล ให้ใช้ปุ่มบันทึก / ไอคอนบันทึกตามที่แบบฟอร์มแสดง แล้วตรวจสถานะและเลขเอกสารก่อนออกจากหน้า
  • ภาพประกอบเป็นข้อมูลจำลอง ชื่อรายการ ภาษา หรือเลขเอกสารอาจต่างจากบัญชีของคุณ ตัวเลขในภาพไม่ใช่ค่าที่ต้องกรอก
  • ข้อความผิดเงื่อนไขให้จดเลขเอกสารและข้อความที่แสดง ส่งให้ผู้รับผิดชอบงานตรวจ อย่าส่งรหัสผ่านหรือข้อมูลเข้าสู่ระบบ
  • ถ้าคู่มือเปิดแล้วภาพหรือภาษาเก่าค้าง ให้บันทึกงานในหน้าระบบก่อน แล้วรีเฟรชแท็บคู่มือ

เริ่มต้นการสื่อสาร

แอปแชทใช้ข้อความตรงและช่องสนทนา ส่วนข้อความ บันทึกโน้ต และกิจกรรมในฟอร์มผูกกับเอกสารแต่ละฉบับ การส่งข้อความหรือทำกิจกรรมเสร็จไม่แทนปุ่มอนุมัติทางธุรกิจของแอปนั้น

  1. เลือกผู้รับหรือเอกสาร
  2. เขียนข้อความ
  3. ติดตามกิจกรรม
  4. กลับตรวจสถานะงาน

ส่งข้อความและใช้ช่องสนทนา

  1. เปิดแอปแชท เลือกข้อความตรงหรือช่องที่ตนเป็นสมาชิก
  2. ตรวจผู้รับและสมาชิกก่อนส่ง โดยเฉพาะเมื่อมีบุคคลภายนอกหรือผู้ใช้ต่างบริษัท
  3. เขียนข้อความให้มีเลขเอกสารและสิ่งที่ต้องดำเนินการ แนบเฉพาะหลักฐานที่เหมาะกับผู้รับ
  4. เมื่อมีลิงก์เอกสาร ให้เปิดและตรวจข้อมูลในเอกสาร ระบบยังตรวจสิทธิ์ตามเอกสารนั้น

ข้อความและโน้ตในเอกสาร

  1. เปิดเอกสารในแอปที่เกี่ยวข้อง แล้วไปส่วนข้อความด้านล่างฟอร์ม
  2. เลือกส่งข้อความเมื่อประสงค์สื่อสารกับผู้รับตามที่ระบบระบุ หรือบันทึกโน้ตเมื่อเป็นบันทึกภายใน
  3. ตรวจผู้ติดตามและผู้รับก่อนส่งข้อความหรือแนบไฟล์
  4. ข้อความเป็นประวัติประกอบงาน ตรวจปุ่มและสถานะเอกสารแยกเมื่อจำเป็นต้องอนุมัติหรือยืนยัน

กิจกรรมและกำหนดติดตาม

  1. ในฟอร์มเอกสาร เลือกกิจกรรม ระบุประเภท ผู้รับผิดชอบ กำหนดวัน และคำอธิบายงาน
  2. ตรวจรายการกิจกรรมที่มุมขวาบนหรือบนเอกสารเพื่อติดตามงานใกล้ครบกำหนด
  3. เมื่อทำงานแล้วให้บันทึกผลกิจกรรม หากเป็นงานอนุมัติให้ทำขั้นตอนในเอกสารด้วย
  4. การแจ้งเตือนบางชนิดขึ้นกับการตั้งค่าระบบและตารางงาน ให้ตรวจเอกสารจริงเมื่อไม่พบการเตือน

คำถามที่พบบ่อย

อาการตรวจอย่างไร
เปิดลิงก์เอกสารไม่ได้สิทธิ์ข้อความและสิทธิ์อ่านเอกสารต่างกัน ให้เจ้าของงานตรวจการมอบหมาย
ส่งข้อความแล้วสถานะไม่เปลี่ยนเปิดเอกสารและใช้ปุ่มขั้นตอนงานตามสิทธิ์
ไม่เห็นช่องสนทนาตรวจสมาชิกช่องและสิทธิ์ของบัญชี
กิจกรรมเสร็จแต่สัญญายังร่างกิจกรรมเป็นการติดตาม ไม่แทนการบันทึกตรวจทาน อนุมัติ หรือเปิดใช้งาน
