หลักประกันการจัดซื้อ

บันทึกหลักประกัน ติดตามครบกำหนด และดำเนินการรับหรือคืนผ่านเอกสารบัญชีที่เชื่อมโยง

สำหรับ เจ้าหน้าที่จัดซื้อ/สัญญา และเจ้าหน้าที่บัญชีผู้รับหรือคืนหลักประกัน · ปรับปรุง 31 ตุลาคม 2569

เปิดระบบคู่มือทุกแอป

ไม่พบข้อความ ลองใช้คำอื่นหรือล้างคำค้นหา

เริ่มใช้งานและอ่านหน้าจอ

เปิดแอปจากเมนูหลัก แล้วเลือก คู่มือการใช้งาน คู่มือเปิดในแท็บใหม่เพื่อให้ดูพร้อมหน้าทำงานได้ เลือกแอปอื่นจากรายการด้านซ้าย หรือค้นหาคำในคู่มือนี้ และใช้ปุ่มพิมพ์ / บันทึก PDF เมื่อต้องการสำเนา

  • ตรวจบริษัทที่มุมขวาบนและหน่วยงานในเอกสารก่อนสร้างหรืออนุมัติ เมนูและปุ่มขึ้นกับสิทธิ์ของบัญชี
  • หลังแก้ข้อมูล ให้ใช้ปุ่มบันทึก / ไอคอนบันทึกตามที่แบบฟอร์มแสดง แล้วตรวจสถานะและเลขเอกสารก่อนออกจากหน้า
  • ภาพประกอบเป็นข้อมูลจำลอง ชื่อรายการ ภาษา หรือเลขเอกสารอาจต่างจากบัญชีของคุณ ตัวเลขในภาพไม่ใช่ค่าที่ต้องกรอก
  • ข้อความผิดเงื่อนไขให้จดเลขเอกสารและข้อความที่แสดง ส่งให้ผู้รับผิดชอบงานตรวจ อย่าส่งรหัสผ่านหรือข้อมูลเข้าสู่ระบบ
  • ถ้าคู่มือเปิดแล้วภาพหรือภาษาเก่าค้าง ให้บันทึกงานในหน้าระบบก่อน แล้วรีเฟรชแท็บคู่มือ

ลำดับงานหลักประกัน

  1. บันทึกทะเบียน
  2. รับหลักประกัน
  3. ติดตามกำหนด
  4. คืนหลักประกัน
  5. ตรวจเอกสารบัญชี

ทะเบียนและเอกสารรับ/คืนต้องตรงคู่ค้า บริษัท และวิธีหลักประกัน ยอดรับแล้วและคืนแล้วอาศัยรายการปลายทาง จึงต้องตรวจสถานะเอกสารบัญชีด้วย

สร้างทะเบียนหลักประกัน

หลักประกันการจัดซื้อ → หลักประกัน → ใหม่

  1. ระบุบริษัท หน่วยงาน คู่ค้า และใบสั่งซื้อหรือข้อตกลงจัดซื้อที่เกี่ยวข้อง
  2. เลือกวิธีและประเภทตราสารที่ตั้งไว้สำหรับงานนั้น
  3. ระบุจำนวนเงิน วันที่รับ เลขเอกสาร และวันครบกำหนด ตรวจวันที่ให้ตรงหลักฐาน
  4. กรอกแหล่งเงินและบัญชีวิเคราะห์ที่เกี่ยวข้อง รวมทั้งหมายเหตุ แล้วบันทึก

บันทึกรับหลักประกัน

  1. ผู้มีสิทธิ์บัญชีเปิดทะเบียนและใช้ปุ่มสร้างเอกสารรับเมื่อวิธีนั้นต้องมีเอกสารบัญชี
  2. ตรวจเอกสารที่เปิดขึ้น คู่ค้า จำนวนเงิน สมุดรายวัน และบัญชีให้ตรงวิธีหลักประกัน
  3. ดำเนินการลงบัญชีและรับชำระตามเอกสารจริงและหน้าที่
  4. กลับทะเบียนและตรวจยอดรับแล้วกับรายการเอกสารบัญชีที่เชื่อม หลีกเลี่ยงกดสร้างซ้ำโดยไม่ตรวจรายการเดิม

คืนหลักประกัน

  1. ตรวจเงื่อนไขคืน เอกสารครบกำหนด ยอดรับ และยอดคืนสะสม
  2. ระบุวันที่คืนเอกสาร/วันที่คืนตามที่ใช้ แล้วสร้างใบเรียกเก็บเงินคืนตามวิธีที่ตั้งไว้
  3. ตรวจเอกสารคืนก่อนลงบัญชีและชำระจริง
  4. ตรวจยอดคืนสะสมไม่เกินยอดที่คืนได้และรักษาลิงก์เอกสารต้นทาง

ติดตามและตรวจประวัติ

ในรายการหลักประกัน ให้ดูวันครบกำหนด เลขเอกสาร ยอดรับ และยอดคืนร่วมกัน เปิดบรรทัดเอกสารบัญชีที่เชื่อมเมื่อมีคำถามเกี่ยวกับยอด การปิดการใช้งานทะเบียนไม่เท่ากับทำการคืนเงินแล้ว

ปัญหาที่พบบ่อย

อาการตรวจอย่างไร
ไม่มีวิธีหรือตราสารให้เลือกให้ผู้จัดการตรวจข้อมูลหลักและบริษัทที่เกี่ยวข้อง
ไม่เห็นปุ่มรับ/คืนปุ่มสร้างเอกสารบัญชีจำกัดตามสิทธิ์บัญชี
ยอดรับหรือยอดคืนยังไม่เปลี่ยนตรวจสถานะและความสัมพันธ์ของเอกสารบัญชีที่สร้าง
แก้วิธีหรือบริษัทไม่ได้รายการที่มีประวัติทางการเงินถูกป้องกัน ให้ใช้กระบวนการแก้เอกสารที่ได้รับอนุญาต

คู่มือที่เกี่ยวข้อง

สั่งซื้อข้อตกลงและสัญญาออกใบแจ้งหนี้และการเงิน
คู่มือนี้อธิบายการใช้งานที่มีในระบบ GovOpsDev ERP ชื่อข้อมูลจริงและสิทธิ์อาจแตกต่างตามการตั้งค่า หากต้องแก้สิทธิ์หรือการตั้งค่าระบบ ให้ผู้ดูแลที่ได้รับมอบหมายดำเนินการ กลับด้านบน
