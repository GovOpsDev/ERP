คู่มือการใช้งาน

เลือกแอปที่ต้องการอ่าน คู่มือแยกตามงาน พร้อมขั้นตอน ภาพประกอบ และวิธีตรวจปัญหาที่พบบ่อย

ทุกแอปมีเมนู “คู่มือการใช้งาน” ให้เปิดอ่านไปพร้อมหน้าทำงานได้ คู่มืออธิบายตามหน้าที่ เมนูและปุ่มจริงขึ้นกับสิทธิ์ของบัญชี

หน่วยงานจัดโครงสร้างองค์กร มอบหมายหน่วยงานให้ผู้ใช้ และประสานสิทธิ์ตามบริษัทข้อมูลงบประมาณพื้นฐานเตรียมแผนและวงเงิน ติดตามภาระผูกพัน และดำเนินการปรับปรุงโดยรักษาประวัติใบขอซื้อสร้างคำขอ ระบุแหล่งงบ ส่งตรวจ และติดตามการนำไปจัดซื้อหรือเบิกค่าใช้จ่ายสั่งซื้อจัดทำใบเสนอราคาและใบสั่งซื้อ เชื่อมใบขอซื้อ ตรวจอนุมัติ และติดตามการรับของหรือบริการออกใบแจ้งหนี้และการเงินตรวจใบเรียกเก็บเงิน ลงบัญชี และติดตามการใช้จริงจากคำขอซื้อ ใบสั่งซื้อ หรือสัญญาข้อตกลงและสัญญาจัดการข้อตกลงตามใบสั่งซื้อ ลงนาม ตรวจทาน อนุมัติทางกฎหมาย และอ่านประวัติฉบับหลักประกันการจัดซื้อบันทึกหลักประกัน ติดตามครบกำหนด และดำเนินการรับหรือคืนผ่านเอกสารบัญชีที่เชื่อมโยงตรวจรับงานตรวจรับสินค้าและบริการ บันทึกคณะกรรมการ ผลประเมินผู้ขาย และส่งต่อการเรียกเก็บเงินคำขอเบิกสินค้าขอสินค้า อนุมัติและจัดหา ติดตามการส่งมอบ รวมถึงบัตร Kanban และการสำรวจบัตรคลังสินค้ารับสินค้า จ่ายและโอนสินค้า จัดการส่วนค้าง คืนสินค้า และตรวจปริมาณคงเหลือทรัพย์สินอ่านทะเบียนที่รับรู้จากต้นทาง เชื่อมรายการค่าเสื่อม และติดตามการโอนหรือจำหน่ายพนักงานจัดการข้อมูลพนักงาน แผนก หน่วยงานหลัก และการสังกัดเพิ่มเติมตามช่วงเวลารายจ่ายบันทึกรายจ่ายจากหลักฐาน ส่งอนุมัติ และจัดการเงินยืม การเคลียร์ และคืนเงินยืมแชทสนทนาภายใน ติดตามกิจกรรม และกลับไปเปิดเอกสารที่เกี่ยวข้องแดชบอร์ดอ่านภาพรวม เลือกขอบเขตและช่วงเวลา และตรวจกลับไปยังเอกสารต้นทาง
