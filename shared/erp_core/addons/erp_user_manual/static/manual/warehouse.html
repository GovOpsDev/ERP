เปิดระบบคู่มือทุกแอป

ไม่พบข้อความ ลองใช้คำอื่นหรือล้างคำค้นหา

เริ่มใช้งานและอ่านหน้าจอ

เปิดแอปจากเมนูหลัก แล้วเลือก คู่มือการใช้งาน คู่มือเปิดในแท็บใหม่เพื่อให้ดูพร้อมหน้าทำงานได้ เลือกแอปอื่นจากรายการด้านซ้าย หรือค้นหาคำในคู่มือนี้ และใช้ปุ่มพิมพ์ / บันทึก PDF เมื่อต้องการสำเนา

  • ตรวจบริษัทที่มุมขวาบนและหน่วยงานในเอกสารก่อนสร้างหรืออนุมัติ เมนูและปุ่มขึ้นกับสิทธิ์ของบัญชี
  • หลังแก้ข้อมูล ให้ใช้ปุ่มบันทึก / ไอคอนบันทึกตามที่แบบฟอร์มแสดง แล้วตรวจสถานะและเลขเอกสารก่อนออกจากหน้า
  • ภาพประกอบเป็นข้อมูลจำลอง ชื่อรายการ ภาษา หรือเลขเอกสารอาจต่างจากบัญชีของคุณ ตัวเลขในภาพไม่ใช่ค่าที่ต้องกรอก
  • ข้อความผิดเงื่อนไขให้จดเลขเอกสารและข้อความที่แสดง ส่งให้ผู้รับผิดชอบงานตรวจ อย่าส่งรหัสผ่านหรือข้อมูลเข้าสู่ระบบ
  • ถ้าคู่มือเปิดแล้วภาพหรือภาษาเก่าค้าง ให้บันทึกงานในหน้าระบบก่อน แล้วรีเฟรชแท็บคู่มือ

ข้อมูลที่ต้องตรงกัน

  1. เอกสารต้นทาง
  2. ตรวจสถานที่และสินค้า
  3. บันทึกจำนวนจริง
  4. ยืนยันการโอน
  5. ติดตามส่วนค้าง / คืน

ตรวจบริษัท คลัง สถานที่ต้นทาง/ปลายทาง หน่วยนับ และประเภทการปฏิบัติการทุกครั้ง เอกสารคลังเชื่อมกับจัดซื้อ คำขอเบิก ตรวจรับ และต้นทุนตามข้อมูลที่ตั้งไว้

รับสินค้าจากใบสั่งซื้อ

คลังสินค้า → การปฏิบัติการ → การรับสินค้า

  1. เปิดรายการรับที่ตรงใบสั่งซื้อ ตรวจผู้ขาย เลขต้นทาง และคลังปลายทาง
  2. กรอกปริมาณรับจริง หากสินค้าติดตามล็อตหรือหมายเลขประจำเครื่อง ให้ระบุรายละเอียดให้ครบ
  3. ตรวจวันและสถานที่ ก่อนใช้ปุ่มตรวจสอบ/ยืนยัน
  4. หากรับไม่ครบ ให้เลือกจัดการส่วนค้างตามความจริง แล้วตรวจรายการรับครั้งถัดไป
  5. ถ้าต้องมีการตรวจรับงาน ให้ดำเนินการตรวจรับในแอปตรวจรับตามนโยบายด้วย

โอนและจ่ายสินค้า

  1. เปิดการโอนจากคำขอหรืองานต้นทางที่เกี่ยวข้อง ไม่สร้างงานซ้ำเมื่อมีเอกสารรออยู่แล้ว
  2. ตรวจสถานที่ต้นทางและปลายทาง รวมทั้งสินค้าที่สำรองไว้
  3. บันทึกปริมาณที่ส่งจริงและยืนยันตามสิทธิ์
  4. กลับไปตรวจคำขอเบิกหรือเอกสารต้นทางว่ายอดส่งมอบสอดคล้องกัน

คืนสินค้าและส่วนค้าง

  1. เปิดเอกสารคลังที่ยืนยันแล้ว ใช้การคืนสินค้าเพื่อสร้างงานกลับทาง
  2. ระบุสินค้าและจำนวนที่คืน ตรวจสถานที่ให้ตรงการคืนจริง
  3. ยืนยันงานคืนแล้วตรวจยอดสุทธิของเอกสารต้นทาง
  4. หากมีผลต่อใบเรียกเก็บเงิน ต้นทุน หรือทรัพย์สิน ให้ประสานผู้รับผิดชอบบัญชีและทรัพย์สินแยกตามเอกสาร

ตรวจนับและการติดตามมูลค่า

ใช้หน้าปริมาณคงเหลือและประวัติการเคลื่อนย้ายเพื่อสอบทานสินค้า การปรับยอดตรวจนับเป็นงานของผู้มีสิทธิ์และต้องอิงผลนับจริง ข้อมูลแหล่งเงินและบัญชีวิเคราะห์ที่ตามจากเอกสารต้นทางใช้ติดตามที่มา การโอนคลังเองไม่ได้สร้างวงเงินงบประมาณใหม่

เมื่อยืนยันรายการไม่ได้

อาการตรวจอย่างไร
จำนวนไม่พอตรวจของคงเหลือ การสำรอง และนโยบายสินค้าติดลบของสถานที่
ต้องระบุล็อต/หมายเลขเปิดรายละเอียดการปฏิบัติการและระบุข้อมูลติดตามสินค้าตามที่ตั้งไว้
ต้นทางต่างบริษัทตรวจบริษัทของคลัง สถานที่ สินค้า และเอกสารที่เชื่อม
อยากแก้การโอนที่จบแล้วใช้การคืนหรือกระบวนการปรับที่ได้รับอนุญาต ไม่แก้ประวัติการเคลื่อนย้ายโดยตรง

คู่มือที่เกี่ยวข้อง

คำขอเบิกสินค้าสั่งซื้อตรวจรับงานทรัพย์สิน
คู่มือนี้อธิบายการใช้งานที่มีในระบบ GovOpsDev ERP ชื่อข้อมูลจริงและสิทธิ์อาจแตกต่างตามการตั้งค่า หากต้องแก้สิทธิ์หรือการตั้งค่าระบบ ให้ผู้ดูแลที่ได้รับมอบหมายดำเนินการ กลับด้านบน
