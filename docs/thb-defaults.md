# สกุลเงินเริ่มต้น THB

`erp_core` รุ่น `20.0.1.1.0` ใช้ THB เป็นค่าเริ่มต้นของบริษัทใหม่ โดยยังเคารพ
สกุลเงินที่ระบุเอง สกุลเงินจาก context และสกุลเงินบริษัทแม่ของสาขา
แอปงบประมาณ จัดซื้อ การเงิน คลัง ทรัพย์สิน สัญญา และแดชบอร์ด ใช้บริษัท
และสกุลเงินเอกสารตามกลไกเดิม ไม่เปลี่ยนเครื่องหมาย USD ให้กลายเป็นบาท

ในการติดตั้งครั้งแรก hook จะตั้งบริษัทเริ่มต้น `My Company` เป็นประเทศไทย + THB เฉพาะ
ฐานที่มีบริษัทเดียว ใช้ค่า USD เริ่มต้น และไม่มีเอกสารธุรกิจในโมดูลที่ติดตั้ง
ไม่เปลี่ยนบริษัทที่ตั้งชื่อแล้ว ฐานหลายบริษัท ฐานที่มีเอกสารเดิม บริษัทที่มี
ผังบัญชีแล้ว หรือประเทศที่ระบุไว้นอกเหนือจาก US เริ่มต้น/TH
การอัปเกรดโมดูลไม่เรียก post-init hook และไม่แปลงข้อมูลเงินเดิม

ผู้ดูแลต้องตรวจประเทศ ผังบัญชี ภาษี และอัตราแลกเปลี่ยนให้เหมาะกับองค์กร
ค่าเริ่มต้น THB ไม่ได้แปลว่าตั้งค่าบัญชีและข้อมูลหลักครบสำหรับ production
เมื่อมีรายการบัญชีแล้ว Odoo ไม่อนุญาตให้เปลี่ยนสกุลเงินบริษัทตรง ๆ
ให้ใช้บริษัท THB ใหม่ หรือวางแผนย้ายข้อมูล/ยอดยกมาอย่างชัดเจน

ราคา `0.0` และสกุลเงิน EUR ใน manifest ของชุด Apps Store เป็น metadata ของ
ราคาแจกฟรีบน Store ไม่ใช่สกุลเงินของบริษัทหรือเอกสารธุรกิจ

## การตรวจ

ชุดทดสอบ Foundation ครอบคลุมบริษัทใหม่ การระบุ USD เอง ค่า context สาขา
และ batch create พร้อมยืนยันว่าการเขียนชื่อบริษัทเดิมไม่เปลี่ยนสกุลเงิน
หลักฐานติดตั้งใหม่และทดสอบรวมอยู่ที่ `test-evidence/thb-defaults-20261031/`
ซึ่งเก็บนอก Git รายงานฉบับนี้ไม่อ้างว่าข้อมูล USD เดิมถูกแปลงเป็นบาท

## บริษัททดลอง local

สร้างบริษัทแยก `GovOpsDev ทดลอง (THB)` โดยใช้ผังบัญชีไทยมาตรฐาน (`th`)
มีบัญชี 148 บัญชี สมุดขาย/ซื้อ/ทั่วไป/ธนาคาร หน่วยงาน แผนก พนักงานทดลอง
คลังสินค้า โปรไฟล์ทรัพย์สิน คู่ค้า สินค้าทดลอง และงบทดลอง 1,000,000 บาท
ในระดับโครงการและแหล่งเงิน ซึ่งเป็นวงเงินเดียวกันที่ควบคุมคนละระดับ
ไม่มีการลงรายการบัญชีจากสคริปต์ตรวจ ฟอร์มฉบับร่างทดสอบถูก rollback ทั้งหมด

`trial_demo` ใช้บริษัท THB ใหม่นี้เป็นค่าเริ่มต้นและยังเลือกบริษัท USD เดิมได้
สิทธิ์กลุ่มเดิมไม่เปลี่ยน Apps/Settings ยังไม่แสดง ผู้ดูแล `admin` เข้าถึง
บริษัทใหม่ได้ด้วย หลังรีเฟรชให้เลือกชื่อบริษัทใหม่นี้จากมุมขวาบน หาก cookie
ของ session ยังเลือกบริษัทเดิมอยู่ การ login ใหม่อย่างเดียวอาจยังใช้บริษัทเดิม

ตรวจสกุลเงินฟอร์มลูกค้า/ผู้ขาย ใบสั่งซื้อ ใบขอซื้อ งบประมาณ และ payload
แดชบอร์ดผ่าน รวมถึงการแยกบริษัท ตรวจ fingerprint ของข้อมูลธุรกิจเดิม
9 ประเภทก่อน/หลังตรงกัน บริษัท USD เดิมทั้งสี่คงสกุลเงินเดิม
การตรวจ browser รอบนี้ยังทำไม่ได้ภายใต้นโยบาย browser จึงไม่อ้างผล UI

ชุดติดตั้งใหม่ครั้งเดียวที่แก้แล้วผ่าน **389 tests: 0 failed, 0 errors** และตรวจ
หลังติดตั้งว่า My Company เป็น THB / ประเทศไทย / ผังบัญชี `th` แดชบอร์ด
ใช้ THB และโมดูลผู้เผยแพร่ทั้ง 14 โมดูลติดตั้งพร้อมโลโก้ครบ

การตรวจครั้งแรกพบว่าเลือก THB อย่างเดียวแต่คงประเทศ US เริ่มต้นไว้ ทำให้
ตัวโหลดผังบัญชีมาตรฐานคืนค่า USD จึงแก้เฉพาะ bootstrap ของ placeholder
ให้กำหนดประเทศและสกุลเงินร่วมกัน และทดสอบใหม่บนฐานว่างอีกชุดจนผ่าน
