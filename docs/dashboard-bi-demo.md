# Dashboard BI Tour: งบประมาณโครงการ

ทัวร์นี้เล่นภาพและข้อมูลที่ Playwright อ่านจาก Dashboard ใน Odoo จริง ตัวเล่น static ไม่ได้เชื่อมต่อ Odoo หรือคำนวณกราฟเอง ชุดสาธิตมาตรฐานคือ PROJECT70-001 และ PROJECT70-002 ภายในบริษัทสังเคราะห์ **สำนักงาน A สูงสุด** บัญชี `interactive-demo` ใช้สิทธิ์เดิม การบันทึกไม่สร้างหรือแก้ไขธุรกรรม

เปิด Odoo ผ่าน **แดชบอร์ด → งบประมาณ → งบประมาณโครงการ · บริษัทปัจจุบัน** (`/odoo/dashboards?dashboard_id=3` ในฐานสาธิตนี้; หมายเลขอาจต่างในฐานอื่น) ภาพรวมเริ่มต้นครอบคลุมทุกโครงการที่ผู้ใช้มีสิทธิ์ จึงรวม DEMO70 ด้วย ภาพกรองโครงการแต่ละรายการแสดงขอบเขต PROJECT70 อย่างชัดเจน

KPI จริงมีวงเงินจัดสรร ผูกพันสุทธิ ใช้จริงสุทธิ รายการไม่ระบุประเภท และคงเหลือ จาก `erp.budget.report` แถวระดับบัญชีวิเคราะห์ที่ active/open: วงเงินเท่ากับผลรวมของผูกพัน ใช้จริง รายการอื่น และคงเหลือ กราฟเลือกมาตรวัดเหล่านี้แยกรายโครงการ/หน่วยงาน; อีกกราฟแสดงรายการสุทธิแยกประเภทงบ การ์ด/กราฟตัดเศษหลังรวมเพื่อการแสดงผล ส่วน Pivot และข้อมูลต้นทางยังมีทศนิยม

ตัวกรองจริงมีปี/รอบงบประมาณ โครงการ/บัญชีวิเคราะห์ หน่วยงาน และ KPI ทัวร์สาธิตการสลับ PROJECT70-001/002 และกรองโครงการร่วมกับหน่วยงาน; ชุดนี้ไม่มี KPI ที่กำหนดจึงไม่แสร้งแสดงผลกรอง KPI เมื่อเลือกแท็บกราฟใช้จริง ตัวกรองยังอยู่ ระบบทดสอบเทียบตัวเลขกับแถวที่ผู้ใช้เข้าถึงได้และตรวจภาพกราฟเปลี่ยน การเปิด Pivot เป็น action แยกที่เริ่มจากทั้งบริษัท ไม่สืบทอดตัวกรอง Dashboard; คลิกยอด PROJECT70-001 เพื่อเปิดรายการวงเงินหนึ่งรายการ ไม่อ้างว่าเปิดใบสั่งซื้อหรือบิลโดยตรง

Run `dashboard-bi-20261101-e` ผ่านการตรวจ 1 พฤศจิกายน 2569 โดยรวมทั้งบริษัท: จัดสรร 6,000,000 = ผูกพัน 1,080,000 + ใช้จริง 596,000 + อื่น 0 + คงเหลือ 4,324,000 บาท PROJECT70-001: 1,000,000 = 60,000 + 222,000 + 0 + 718,000; PROJECT70-002: 800,000 = 400,000 + 0 + 0 + 400,000 การล้างคืนภาพรวมเดิม บริษัทนอกสิทธิ์ถูกปฏิเสธ HTTP 403

สร้างหลักฐานซ้ำโดยกำหนด `DASHBOARD_TOUR_RUN`, `DASHBOARD_TOUR_OUTPUT`, `BUDGET_BI_PASSWORD_FILE` และ `ODOO_BASE_URL` แล้วรัน `npx playwright test --config=dashboard-tour.config.cjs` จาก `playwright-demo/`; credential ต้องเก็บนอก repository ตรวจภาพและ metadata ทุกไฟล์ก่อนใช้ `scripts/review-demo-evidence.py` แล้ว `scripts/build-guided-tour.py <run-id>` หลักฐานเผยแพร่อยู่ที่ `guided-tour/generated-bi/` raw run และไฟล์รหัสผ่านไม่เผยแพร่

ข้อจำกัด: การสาธิตเป็นภาพต่อเนื่องจากข้อมูลสังเคราะห์ การกรองและการ drill-down จริงเกิดขึ้นใน Odoo ระหว่างบันทึก ไม่เกิดในภาพ static ค่าและ ID อาจเปลี่ยนตามฐานข้อมูล ไม่ใช่การทดสอบข้อมูล production หรือทุกประเภทสิทธิ์
