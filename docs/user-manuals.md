# คู่มือ HTML ของ GovOpsDev ERP

โมดูล `erp_user_manual` เพิ่มเมนู **คู่มือการใช้งาน** ใต้แอปที่บัญชีทดลอง
ใช้งานอยู่ครบ 15 แอป และเปิดหน้า HTML ในแท็บใหม่:

| แอป | หน้า HTML |
|---|---|
| หน่วยงาน | organization.html |
| ข้อมูลงบประมาณพื้นฐาน | budget.html |
| ใบขอซื้อ | procurement.html |
| สั่งซื้อ | purchase.html |
| ออกใบแจ้งหนี้ | finance.html |
| ข้อตกลง | agreements.html |
| หลักประกันการจัดซื้อ | guarantees.html |
| ตรวจรับงาน | acceptance.html |
| คำขอเบิกสินค้า | stock_requests.html |
| คลังสินค้า | warehouse.html |
| ทรัพย์สิน | assets.html |
| พนักงาน | employees.html |
| รายจ่าย | expenses.html |
| แชท | chat.html |
| แดชบอร์ด | dashboards.html |

หน้ารวมอยู่ที่ `/erp_user_manual/static/manual/index.html` คู่มือมีสารบัญ
ค้นหาข้อความในหน้า เปลี่ยนคู่มือ เชื่อมงานที่เกี่ยวข้อง และรูปแบบสำหรับ
พิมพ์ / บันทึก PDF จาก browser ภาพประกอบ 10 ภาพใช้ข้อมูลสังเคราะห์จาก
ฐานทดสอบแยก ไม่มีข้อมูลเข้าสู่ระบบหรือข้อมูล production

แยกโมดูลเอกสารออกจากโมดูลธุรกิจ ใช้ action URL ตามรูปแบบคู่มือ HTML
ที่มีอยู่แล้วใน workspace ไม่เพิ่มโมเดลธุรกิจ ไม่เปลี่ยน ACL และไม่เพิ่ม
สิทธิ์ Apps/Settings ให้บัญชีทดลอง เนื้อหาคู่มือเป็น static HTML จึงไม่ใช่
กลไกตรวจสิทธิ์ข้อมูลธุรกิจ ผู้ใช้ยังต้องมีสิทธิ์เอกสารจริงตามเดิม

ดูที่มาของขั้นตอนและวิธีตรวจใน `shared/erp_core/addons/erp_user_manual/README.md`
ก่อนแก้เนื้อหา ส่งออกภาพใหม่จากข้อมูลจำลองเมื่อหน้าจอเปลี่ยน และคงคำอธิบาย
สกุลเงินจริง ข้อจำกัดวัน พ.ศ./ค.ศ. และการรักษาประวัติฉบับตามระบบที่ใช้งาน

ผลทดสอบและภาพตรวจหน้าจอเก็บนอก Git ที่
`test-evidence/manuals-20261031/` ในระดับเดียวกับ repository `org`

ตรวจบนฐานจำลองและบน local ด้วยบัญชี `trial_demo` แล้ว: คลิกเมนูจริงครบ
15 แอป เปิด HTML 16 หน้า ภาพโหลดครบ ค้นหาได้ทุกคู่มือ และตรวจหน้าจอมือถือ/
รูปแบบพิมพ์ 3 คู่มือตัวแทน ไม่พบ browser runtime error ข้อมูลธุรกิจ 16 ตาราง
มี count/fingerprint ตรงกันระหว่างหยุด writer ก่อนและหลังติดตั้ง และข้อจำกัด
Apps/Settings ของบัญชีทดลองยังผ่านการตรวจตามเดิม ดูผลรวมใน `summary.json`

## FAQ การเปลี่ยนสกุลเงิน — 20.0.1.1.0

เพิ่ม FAQ ภาษาไทยในคู่มือครบ 15 แอปและหน้ารวม พร้อมลิงก์ในสารบัญ
และคำตอบเฉพาะแอป อธิบายการตั้ง THB ที่บริษัท การเลือกสกุลเงินเอกสาร
ข้อจำกัดเมื่อมีรายการบัญชี วิธีใช้บริษัททดลองใหม่ การเปิดใช้สกุลเงิน/อัตรา
สิทธิ์ผู้ใช้ และการตรวจบริษัทกับเอกสารต้นทางเมื่อแดชบอร์ดยังแสดง USD
เนื้อหาเป็น HTML จริง จึงค้นหาและพิมพ์ได้โดยไม่ต้องโหลดเนื้อหาเพิ่มเติม

การตรวจรอบนี้แยกจากผลทดสอบคู่มือครั้งแรกที่รายงานไว้ด้านบน:
ตรวจหน้า HTML 16 หน้า ลิงก์และรูปเดิม และอัปเกรดโมดูลคู่มือบน local
โดยไม่เปลี่ยนข้อมูลธุรกิจหรือสิทธิ์ Browser rendering รอบนี้ยัง NOT TESTED
